# Decisions

| Date | Decision | Why |
|---|---|---|
| 2026-11-19 | Content: stepdown first, small CTICU section second | He stays on 5 St. John and cross-trains in CTICU. Basic rhythm ID alone bores him (passed the exam at several hospitals) |
| 2026-11-19 | Phone web app, offline, Add to Home Screen | Used on breaks on night shift, often without signal. No app store needed |
| 2026-11-19 | Plain HTML/CSS/JS, no dependencies, no backend | Same approach as the owner's Diary app. Nothing to install, nothing to hack, works offline |
| 2026-11-19 | Public repo, hosted on GitHub Pages | Free hosting requires public on the free plan. Repo holds no personal or patient data |
| 2026-11-19 | Strips generated by code, not images | No copyright problems, unlimited new strips, can't be memorized |
| 2026-11-19 | Draw on `<canvas>` | Smooth 60 fps live sweep with many points; calipers drawn on top |
| 2026-11-19 | Dark monitor look, dark only in v1 | Night shift, low glare, feels like the bedside monitor |
| 2026-11-19 | Every clinical fact cites a source; nurse reviews before "reviewed" | Wrong medical content is worse than none |
| 2026-11-19 | No HUMC policy content | Policies are internal and vary; app is a study aid |
| 2026-11-19 | Phase 1 widened to a full working trainer for 5 rhythms | Owner asked for something usable now; he's retaking the exam and struggles with test anxiety |
| 2026-11-19 | Explanations computed from the strip's own measurements | Feedback matches what's on screen; tests prove the answer key and every "why not" agree with the strip |
| 2026-11-19 | Gaussian beat model (after ECGSYN), own code | Established published approach, no GPL code copied, every parameter tied to a criterion |
| 2026-11-19 | Generated rates keep a margin from cutoffs | No unfair borderline strips while the set is small |
| 2026-11-19 | Exam: hide-able countdown, calm tips, misses go to review | Test anxiety: practice the clock, then turn every miss into practice |
| 2026-11-19 | 3D campus documented, not built; clinical phases first | Exam prep is the urgent need; 3D adds a dependency and needs verified references first |
| 2026-11-19 | Future 3D engine: vendored Three.js, not React Three Fiber; Remotion only for rendered cutscenes | Keeps the no-build architecture; Remotion renders frame-driven video, not interactive scenes |
| 2026-11-19 | Campus priorities corrected: main hospital with St. John (old, ~6 stories, part of the connected complex), the existing Pavilion, Helena Theurer Pavilion, Medical Plaza, research tower, Women's and Children's, JTCC last | Owner knowledge plus the official 2024 campus map; recognizability by staff is the bar |
| 2026-11-19 | Fountain is decoration in a real location, not a reward; mastery shows through building light and detail, never extra floors | Keep the campus truthful at every stage |
| 2026-11-19 | Spaced repetition: FSRS (default parameters), not SM-2 | Recall probability per skill powers "likely to forget" sessions and honest mastery for the campus |
| 2026-11-19 | Photo import is optional, on-device, opt-in for any external AI | Privacy promise; patient data must never enter the app |
| 2026-11-19 | Cinematic intro and iPhone walkthrough are separate; both made only from finished features | No advertising features that don't exist |
| 2026-11-19 | The nurse's name stays out of the repo | Public repo; CLAUDE.md bans staff names |
| 2026-11-19 | Phase 2: 26 rhythms; paced rhythms deferred to the post-op side-track | Paced strips need their own sources and the CTICU context; the exam-critical set comes first |
| 2026-11-19 | Answer key as feature sets (rate, regularity pattern, atrial activity, PR behavior, QRS, ectopy, shape) | Scales to 26 rhythms; every "why not" names the exact feature that fails; tests prove each pair of rhythms is told apart on every strip |
| 2026-11-19 | Generator builds events first (P waves, conduction, drops, ectopics), then draws | Blocks and ectopy need P waves that aren't tied 1:1 to QRS complexes |
| 2026-11-19 | Borderline strips are opt-in (Practice toggle, exam "Mix in" about 1 in 4) | Practice the cutoffs on purpose, without making the default drill feel unfair |
| 2026-11-19 | No 2:1 AV block question | LITFL: type I vs II often can't be told apart at 2:1; asking would teach guessing |
| 2026-11-19 | AIVR 50 to 100, VT over 100, generator avoids 100 to 110 | LITFL AIVR (50 to 120, VT over 110) and StatPearls VT (over 100) disagree; the app avoids the zone and says so on the card |
| 2026-11-19 | Exam prefs get optional `set` and `edge` fields without a key bump | Additive with defaults, so old `ekg.prefs.v1` data still loads unchanged |
| 2026-11-19 | Premium UI, icon and onboarding come before adaptive learning; onboarding moves up from step 8 | Owner tested phase 2 on the iPhone and wants it to feel like a premium App Store app first |
| 2026-11-19 | App icon and icon system drawn as code (SVG), rendered to PNG locally | Exact P-QRS-T shape, crisp at every size, one consistent stroke system, works offline, editable later; AI image tools give inconsistent raster art |
| 2026-11-19 | Home tab shows accuracy (last 20 answers), never "mastery"; untried reads "not tried yet" | Mastery needs the step 3 model; a 0% for an untried group would be false |
| 2026-11-19 | One rule-based "Suggested next" with its reason on screen (misses, untried group, thin data, lowest group, else exam) | Transparent and testable; no fake intelligence before step 3 |
| 2026-11-19 | Intro shown once per intro version via an additive `tour` field in `ekg.prefs.v1` | Existing users see it once too; no key bump needed since old data loads unchanged |
| 2026-11-19 | Intro screenshots are captured from the real app by a dev script, with sample progress data | Real UI, reproducible after UI changes, no personal data |
| 2026-11-19 | Dev-only Playwright scripts live in `tools/`; the app stays dependency-free | Icons and screenshots are generated, but nothing new ships or loads at runtime |
| 2026-11-19 | Full-screen strip turns the strip sideways instead of relying on rotation | Manifest locks portrait; sideways gives about 2.5x the size on a phone. Calipers stay on the normal view |
| 2026-11-19 | Revised identity: light default, polished dark mode, user choice with System default (replaces "dark only") | Owner wants a premium healthcare-tech look; System still gives dark at night on an iPhone set to automatic |
| 2026-11-19 | App theme and strip theme are separate settings (paper, green monitor, amber monitor) | Shell can look premium while strips stay clinically realistic |
| 2026-11-19 | Healthcare-tech palette in our own blue and teal, not HMH brand colors or marks | Avoid implying endorsement in a public repo; CLAUDE.md bans HMH branding |
| 2026-11-19 | Orange is an accent only, never a status color | Keeps green/red/amber meanings intact and the app calm |
| 2026-11-19 | App icon: blue-teal tile, white trace, orange pen dot | Matches the new identity; still a real P-QRS-T and readable at 60 pt |
